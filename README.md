# Buzzer Dynasty

Un jeu idle de basket dans un style arcade années 90. Tu tires, tu recrutes, tu montes ton club saison après saison, et tu vises le Hall of Fame. Les équipes et les joueurs sont fictifs.

**Jouer :** https://chondocs.github.io/Idle-baller/

## Fichiers

| Fichier      | Rôle                                         |
| ------------ | -------------------------------------------- |
| `index.html` | Structure de la page, icônes                 |
| `style.css`  | Styles (mobile d'abord, mise en page tablette) |
| `i18n.js`    | Textes français (avec féminin) et anglais    |
| `main.js`    | Logique du jeu, rendu, sauvegarde            |

Pas de build ni de dépendances : on ouvre `index.html` et ça tourne. La progression est enregistrée dans le navigateur (export/import disponible dans le jeu).
